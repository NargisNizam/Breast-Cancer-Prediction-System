# 🩺 Breast Cancer Prediction System

A professional Machine Learning web application that predicts whether a breast tumor is **Benign** or **Malignant** using the Breast Cancer Wisconsin Dataset. The application is powered by **FastAPI** and **Scikit-learn**, with a clean medical-themed user interface.

---

## 📖 Overview

This project demonstrates the complete Machine Learning workflow, including:

- Data Loading
- Data Preprocessing
- Model Training
- Model Evaluation
- Model Deployment using FastAPI
- Interactive Web Interface

The trained model classifies breast tumors into:

- 🔴 Malignant
- 🟢 Benign

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Breast-Cancer-Prediction-System.git
```

### 2️⃣ Navigate to the Project

```bash
cd Breast-Cancer-Prediction-System
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Train the Model

```bash
python train.py
```

### 5️⃣ Run the Application

```bash
uvicorn main:app --reload
```
